CAPSTONE PROJECT

LOCKANDGO

Solar-Powered Smart Bicycle Locker System

PROJECT OVERVIEW

About LOCKANDGO

LOCKANDGO is a solar-powered smart bicycle locker system with mobile application access and secure electronic locking designed for City of Malabon University.

The project integrates a mobile application, Firebase, ESP32, QR-based access, TFT display, relay module, electronic solenoid lock, and solar-powered components.

PROJECT OBJECTIVES

Objectives

  • Develop a secure bicycle locker system.
  • Provide mobile application access to the bicycle locker.
  • Implement QR-based locker access.
  • Integrate Firebase for system data and locker status.
  • Use an ESP32 as the main hardware controller.
  • Integrate solar power into the system.

TECHNOLOGIES

Technologies Used

Flutter Firebase ESP32 Arduino QR Code TFT Display Relay Module Solenoid Lock Solar Power

SYSTEM PROCESS

How the System Works

01

Mobile Application

The user accesses the LOCKANDGO system through the mobile application.

02

Firebase

Firebase handles system data and locker status information.

03

ESP32

The ESP32 communicates with the system and controls the electronic lock.

04

QR Access

The QR-based access process is used for locker operation.

05

Electronic Lock

The relay controls the electronic solenoid locking mechanism.

HARDWARE DEVELOPMENT

Hardware Development

The hardware component of LOCKANDGO was developed and assembled step by step. Each component was tested before being integrated into the complete system.

01. ESP32 Controller

The ESP32 serves as the main controller of the smart locker system.

02. TFT Display

The TFT display is used as part of the locker interface and QR display system.

03. Relay Module

The relay module is used to control the electronic locking mechanism.

04. DC-DC BUCK

The DC-DC buck is used to control the supply of voltage from solar panel.

04. Solenoid Lock

The electronic solenoid lock provides the physical locking mechanism for the bicycle locker.

05. Solar Power System

Solar power components provide the energy source for the system.

06. Solar Charge Controller

Solar Charge Controller is an essential hardware device in a solar power system that regulates the voltage and current coming from solar panels before it reaches the battery bank.

06. Wiring and Assembly

The components were connected and assembled to form the complete hardware system.

MOBILE APPLICATION

Mobile Application

The mobile application provides the user interface for accessing and interacting with the LOCKANDGO system.

TESTING

System Testing

The system components were tested individually and then integrated to evaluate the operation of the complete prototype.
