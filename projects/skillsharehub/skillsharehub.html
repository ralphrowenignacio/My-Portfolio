WEB DEVELOPMENT PROJECT

Skill Share Hub

A Collaborative Learning Platform for Students

PROJECT OVERVIEW

About Skill Share Hub

Skill Share Hub is a web-based collaborative learning platform designed to provide students with a centralized environment for accessing and sharing learning resources.

The system provides separate functions for students and administrators, allowing students to access learning materials while administrators manage users, courses, and uploaded resources.

PROJECT OBJECTIVES

Objectives

The project was developed to provide students with a structured platform for collaborative learning and resource sharing.

  • Provide students with a centralized learning platform.
  • Allow students to access and share learning resources.
  • Organize learning materials according to courses and academic programs.
  • Provide administrators with tools for managing users and uploaded resources.
  • Provide separate access and functions for students and administrators.

SYSTEM PROCESS

How the System Works

Skill Share Hub follows a user authentication and resource management process.

01

Registration

Students create an account by providing their required information.

02

Login

Registered users log in to access the appropriate system dashboard.

03

Dashboard

Users are directed to their respective student or administrator dashboard.

04

Learning Resources

Students can access available courses and learning resources.

05

Administration

Administrators manage users, courses, and uploaded resources.

SYSTEM FEATURES

Main Features

The platform contains different features designed for students and administrators.

01

User Registration

Students can create an account and provide their academic information.

02

User Login

Registered users can securely access their accounts.

03

Student Dashboard

Provides students with access to the platform's learning features.

04

Course Filtering

Learning resources can be organized according to academic course categories.

05

Admin Management

Administrators can manage users and review uploaded learning resources.

06

Profile Management

Users can manage their profile information and account settings.

DATABASE

Database Structure

Skill Share Hub uses a MariaDB database named skillshare to store system information.

The database supports user accounts, roles, academic information, and other information required by the learning platform.

DEVELOPMENT

Project Development

The project was developed as a web-based system using PHP for the application logic and MariaDB for database management.

XAMPP was used as the local development environment for running the PHP application and database.

The interface was developed using HTML and CSS, with JavaScript used for interactive elements where necessary.
